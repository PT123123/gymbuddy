# 爬楼：结束不响铃 + 计层/计时分区 + 实时记录（2026-10-21）

## 改了什么

1. **「✓ 结束（本次）」不再触发任何铃声提醒**。响铃只归倒计时：记一趟后自动开的休息归零才响（`soundType=5`，回合标识 `stair.restEndAt`，见 [countdown-dedup.md](countdown-dedup.md)）。设置页铃声场景表同步删掉「爬楼完成」档（原生侧 type=6 配置键不再被前端使用）。
2. **训练页拆成两张卡，用卡片标题做分隔**：
   - 「🪜 计层 · 实时记录」：本趟增量/累计层数常显行 + 大号总层数 + `+1/+5/+10` + 手动总层数 + 「📍 记一趟」+ 趟次列表 + 实时记录列表；
   - 「⏱ 计时 · 休息」：总走表 + 开始/暂停/重置 + 手动休息 + 休息条 + 休息时长/体重 + 「✓ 结束（本次）」+ 「🏁 结束一整天」。
3. **实时记录**：每按一次 `+N` 立即落一条 `{t, inc, total}`（最新在顶，上限 500 条）；手动上调按 `手动 +N 层` 记一条，下调只修总数不记增量。手动改动同时归属当前趟（`lapFloors` 跟 diff 走，钳到 ≥0）。
4. **趟次结算**：`记一趟` 生成的趟带 `{t, floors, dur, rest}`，其中 `rest`（秒）= 该趟休息实际用时，休息结束（归零后继续爬/「结束休息」/「✓ 结束」）时结算落回这趟；手动开的休息默认归最近一趟。
5. **「🏁 结束一整天」在录制中就可见**（完成卡也有）：`stairEndDay()` = 本次爬楼没收口就先 `stairFinish()`，再走训练页 `endTraining()`。`endTraining()` 支持纯爬楼日：今日零结构化记录不再拦路，当日爬楼逐次（时长/层/趟/kcal/休息）写进导出笔记，零训练记录时不再打印「组数：0 组」噪声。

## 数据口径（单位容易踩坑）

- `stair.sessions[i].rest` 是**毫秒**（沿用 1.2.28）；`lapList[i].rest` 与 `stair.laps[i].rest` 是**秒**。
- session 新增 `lapList`（趟次明细）与 `ticks`（正序的实时增量记录）；旧 session 没有这两个字段，导出/展示都按 `Array.isArray` 判空。
- `ticks`/`laps` 只在本次录制内存中，关页面重开清空（与改动前一致）；落盘的是聚合后的 session。
